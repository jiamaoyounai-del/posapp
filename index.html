GitHub (`posapp`) リポジトリ ＆ Firebase Hosting デプロイ完全ガイド

1. GitHubリポジトリ作成とコードプッシュ

  1. ローカルPCで作成したこのコードを index.html という名前で保存します。
  2. GitHubで posapp という名前の新規リポジトリを作成します。
  3. ターミナルで以下を実行しGitHubへ保存します：
git init
git add index.html
git commit -m "Deploy posapp"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/posapp.git
git push -u origin main

2. Firebase Hosting への公開コマンド

  1. Firebase CLI導入: npm install -g firebase-tools
  2. ログイン: firebase login
  3. 初期化: firebase init hosting（プロジェクト kasige-f6216 を選択）
  4. Public Directory は . (現在のディレクトリ) を指定します。
  5. デプロイ実行: firebase deploy --only hosting
